Core Banking
Intelligence Digest

A Python application for monitoring developments in core banking technology and delivering a structured daily email briefing.

Version 1.0 · Deployed October 2026 Python · Google Colab · GitHub Actions · RSS Source Repository Private

01 / Overview

Why I Built It

Working in banking technology, I wanted a more structured way of keeping up with developments across core banking platforms, modernisation programmes and the growing use of artificial intelligence in financial services. Checking several sources individually was time-consuming, so I decided to automate the process.

The result is a Python-based news monitoring application that collects relevant headlines, filters out older or duplicate results, and prepares a daily email digest. It also sends a standard update when no new articles are found. If the news feeds are unavailable, the application reports that separately rather than incorrectly treating the day as quiet.

I developed and tested the application in Google Colab before deploying it through a private GitHub repository. GitHub Actions handles execution, while a dedicated sending email account and repository secrets keep credentials outside the code.

02 / Functionality

Key Features

Targeted Monitoring

Searches RSS results for core banking transformation, Temenos, Mambu, Thought Machine and AI in banking.

News Filtering

Checks publication dates, removes duplicate headlines within each run and limits the briefing to 12 results.

Reliable Messaging Logic

Produces a daily digest, a no-news confirmation or a source-unavailable warning, with manual testing supported.

06 / Reflection

Lessons Learned

From Notebook to Deployment

Colab worked well for writing and testing the application, but a cloud-hosted workflow was better suited to recurring execution without relying on an open browser session.

Authentication and Security

The most challenging part was resolving Gmail SMTP authentication. The issue highlighted the importance of dedicated application credentials, account verification and keeping secrets outside source code.

Handling Exceptional Scenarios

A quiet news day is not the same as an unavailable source. Designing distinct messages for these outcomes made the application's behaviour easier to interpret and test.

Testing Beyond a Successful Run

Unit tests checked individual behaviours, while manually triggering the GitHub workflow and confirming delivery helped validate the end-to-end process.

Development Approach

This personal project was developed with generative AI assistance. I defined the use case and requirements, worked through the Colab and GitHub setup, troubleshot authentication failures and validated the deployed workflow. The application is currently a rule-based automation rather than an autonomous AI agent.
