Core Banking
Intelligence Digest

A Python application for monitoring developments in core banking technology and delivering a structured daily email briefing.

Version 1.0 · Deployed October 2026 Python · Google Colab · GitHub Actions Private Source Repository

01 / Overview

Project Overview

Working in banking technology, I wanted a more structured way of keeping up with developments across core banking platforms, modernisation programmes and the growing use of artificial intelligence in financial services. Checking several news sources individually was time-consuming, so I decided to automate the process.

I developed a Python-based application that collects relevant headlines, filters older or duplicate results and prepares a daily email briefing. It also sends a standard update when no new articles are identified, rather than simply remaining silent.

The application was initially developed and tested using Google Colab before being deployed through a private GitHub repository. GitHub Actions manages scheduled and manual execution, while a dedicated sending account and repository secrets protect email credentials.

02 / Functionality

Key Features

Targeted Monitoring

Retrieves news relating to core banking transformation, Temenos, Mambu, Thought Machine and AI applications within financial services.

News Filtering

Uses publication dates to identify recent articles, removes duplicate headlines within each execution and limits the digest to 12 stories.

Automated Email Delivery

Generates a daily briefing, a default no-news notification or an unavailable-source warning depending on the results of each execution.

03 / Solution Design

Solution Architecture

The initial release uses a rule-based workflow. Rather than introducing an LLM immediately, I focused on establishing a functioning automated process that could be tested and extended over time.

Deployment: The workflow has been executed successfully through GitHub Actions, with manual email delivery confirmed. Daily execution is configured for 07:17 London time, subject to GitHub Actions scheduling availability.

06 / Reflection

Lessons Learned

From Colab to Deployment

Google Colab provided a straightforward environment for developing and testing the application. Moving it to GitHub Actions demonstrated how a Python script could operate independently of a local computer or notebook session.

Authentication and Security

Configuring Gmail authentication proved more challenging than expected. Resolving the SMTP errors required understanding Google App Passwords and account verification. It also reinforced the importance of separating credentials from source code.

Handling Different Outcomes

One important design decision was distinguishing between days with no relevant news and situations where the news sources were unavailable. Treating these as separate outcomes made the application easier to understand and validate.

Testing the Complete Workflow

Automated tests provided confidence in the individual functions, but successfully executing the workflow in GitHub and receiving the email was an important final step. It highlighted the difference between testing code and validating a deployed application.

Development Approach

This personal project was developed with generative AI assistance. I defined the use case and functional requirements, worked through the Python and GitHub setup, troubleshot authentication problems and validated the deployed application. The current version is a rule-based news monitoring automation rather than a fully autonomous AI agent.
